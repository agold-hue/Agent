# Data files the playbooks create on demand

Create these when first needed (not seeded): `writing-style.md`, `health.md`, `ledger.md`, `career.md`, `board.md`, `calendar-archive.md`, `projects/done/`, `sites/<domain>.md`, `history/`.
Keep every file under 100 kB; roll into `<name>-<year>.md` when it grows.

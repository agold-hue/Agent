# Work playbook (a 9-5 owner)

Data: profile.md (Work, Interruptions), calendar, renewals.md, ledger.md, career.md.

## Errands during work hours
- Anything that only happens 9-5 is yours: government appointments, banks, pharmacies, contractors, utilities, insurers, returns. Do it during the user's work day and text the outcome. If someone needs the user in person, book the slot per the calendar guard and put it on the calendar with what to bring.

## Interruption rhythm
- The user is at work. Non-urgent items wait for the check-ins (BATCH_TIMES, typically lunch and end of day); the host holds them for you. Start a report with "URGENT:" only for money leaving, a same-day deadline, or family.
- In each check-in: one text, most important first, one line per item, questions phrased for a one-word answer.

## Commute guard
- Never schedule anything during work hours or commute (profile.md). Preferred slots: early morning, lunch, after work, Saturday. Deliveries: a day someone is home, or a pickup point.

## Paycheck and benefits
- See money.md Payday. Benefits deadlines (open enrollment, FSA use-it-or-lose-it, HSA contributions, 401k changes) in renewals.md with watches two weeks ahead; explain the choice in three lines and draft the form.
- Reimbursements: collect receipts, build the report in the employer's format, remind the user to submit (or submit through the portal if allowed).

## PTO and time off
- See travel.md PTO planning. Keep the balance in profile.md; draft requests; set the out-of-office draft; block the calendar.

## Career upkeep
- career.md holds the resume text, LinkedIn summary, and a running list of wins the user mentions ("shipped X", "got the award"). Monthly: propose resume and LinkedIn updates from the wins; the user approves and pastes (or you update LinkedIn in the browser with a checkpoint).
- Job watch: if the user sets criteria, a daily watch on the job boards they name; three matches a week at most, one line each. Interview prep on request: company research, likely questions, the user's relevant stories from career.md.

## Learning
- See paperwork.md Learning and certifications.

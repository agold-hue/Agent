# Playbooks

How the agent handles each domain. Read the matching one before starting a task in that domain; refine it after (keep each under ~60 lines). The user may edit these directly.

- calendar.md: scheduling with others, calendar defense, commute guard, daily and weekly reviews
- inbox.md: the user's own inbox: triage, delegation, drafts in the user's voice, action items
- money.md: bills, subscriptions, money watch, receipts and expenses, side income and taxes, budget
- shopping.md: reorders, price watches, returns, groceries
- home.md: home services, deliveries, food and reservations, household logistics
- health.md: appointments, refills, insurance claims and appeals
- travel.md: trips end to end, PTO planning
- paperwork.md: forms, PDFs, signatures, filing to Drive, renewals and deadlines, certifications
- people.md: relationships, occasions, meeting prep and debriefs, one-on-ones
- research.md: research and decisions, reading and summaries, the signals digest
- work.md: the 9-5 owner: errands during work hours, batching, paycheck and benefits, career upkeep
- executive.md: board and investor cadence, contracts, hiring pipeline, company action items
- kids.md: school mail, forms, activities, coordinating with the other parent

# Watchlist

Things the agent keeps an eye on without being asked, and the recurring watches it has set
(`schedule_follow_up` with `repeat`). One line each: what, how often, what to do, watch id.

Examples of what belongs here: a flight price to buy under $X, a bill that is due on the 15th,
a package that should arrive by Friday, a subscription renewal to cancel before it bills,
tickets that go on sale at 10am.
